Execution semantics — enforced repo-wide by an AST audit (test_execution_semantics.py)

tool attempt ≠ tool success
process exit 0 ≠ mission success
HTTP 200 ≠ capability success
agent narrative ≠ evidence
model completion ≠ mission completion
Six stages, never collapsed: 1 accepted → 2 authorized → 3 connector invoked → 4 remote acked → 5 execution confirmed → 6 mission success. A connector returning normally proves stage 3. SUCCEEDED asserts stage 5. CallStatus.UNKNOWN exists for external actions whose effect cannot be observed.
