# knowledge/

The five L2 knowledge stores: Enterprise Knowledge Graph, Causal Graph,
CAD/PLM Semantic Index, Cost & Supply Graph, Decision Memory. Queried by
[`../agents/`](../agents/) through typed capabilities, never via raw graph
query language from outside this module.

Relevant chapters: [002-knowledge-graph](../docs/002-knowledge-graph.md),
[003-causal-graph](../docs/003-causal-graph.md) — together the rationale
for why these are kept as separate stores rather than one graph (see
[ADR-0007](../adr/0007-separate-knowledge-and-causal-graphs.md)).

Roadmap: Phase 2 (Knowledge Graph, Causal Graph, Digital Twin).
